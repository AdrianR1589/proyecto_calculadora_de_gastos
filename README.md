# proyecto_calculadora_de_gastos
Proyecto de una calculadora de gastos que te ayude a clasificar y obtener los gastos que tienes

CALCULADORA DE GASTOS
El objetivo es que la puedan usar y distinguir la cantidad de gastos que ocupan por cada categoria, para que ellos mismos tomen las desiciones necesarias, de acuerdo, su registro de los datos.
